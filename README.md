# AutoLoc

## Acteurs

- Client
- Agent d'agence
- Responsable d'agence
- Administrateur

## Cas d'utilisation

### Client
- Consulter les véhicules
- Réserver un véhicule
- Gérer ses réservations

### Agent d'agence
- Gérer les réservations
- Gérer les clients

### Responsable d'agence
- Superviser l'agence
- Consulter les statistiques

### Administrateur
- Gérer les utilisateurs
- Gérer le système
